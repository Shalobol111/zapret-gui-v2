# DESIGN.md — редизайн ZapretGUI 2.0

Спецификация для разработчика (ИИ-агента). Положите этот файл в корень репозитория

**Макет (источник правды по внешнему виду):** https://claude.ai/artifact/9LB5De7j8kPWiQT6h2NeMm
Четыре экрана: `Main.dc.html` (Главная), `Check.dc.html` (Проверка), `Lists.dc.html` (Списки), `Settings.dc.html` (Настройки). Если в Claude Code доступен инструмент Artifact, прочитай файлы макета: `action: read`, `path: project/<имя>.dc.html`. Там точные цвета, отступы и тексты. Если этот файл и макет расходятся, верен макет.

## 0. Главные правила
- Все тексты интерфейса на русском, как в макете. **Никаких эмодзи** на кнопках (сейчас там 💾 📋 🔍 ⬇ ⊕). Иконки — монохромные линейные (см. раздел 5).
- Окно по умолчанию 960×640, минимум 780×600 (как сейчас).

## 1. Структура: 6 вкладок → 4 раздела

| Было (`CTkTabview`) | Стало (боковое меню) |
|---|---|
| Управление + Службы | **Главная** |
| Диагностика + Тесты | **Проверка** |
| Конфигурация | **Списки** |
| Настройки | **Настройки** |
| Постоянный журнал 215 px снизу | Сворачиваемая карточка «Журнал» только на Главной |

Действие «Удалить службы» переезжает в меню «⋯» карточки службы или в Настройки (опасное действие не стоит на виду рядом с «Установить»).

- Sidebar: фон `side`, справа граница 1 px `line`. Логотип: квадрат 28 px (radius 8, фон `raised`, рамка `line2`) с иконкой «стрелки туда-обратно» цвета `accent`, рядом «zapret» 15/600 и «GUI 2.0» 11 `faint`.
- Пункт меню: высота 40, radius 10, отступ 12, иконка 18 + текст 14. Активный: фон `raised`, текст `tx`, вес 500. Неактивный: прозрачный, текст `dim`. У «Главной» справа точка 6 px `accent`, когда обход включён.
- Низ sidebar: плашка «Администратор» (высота 40, рамка `line`, иконка щита `accent`, текст 12 `dim`; без прав — щит `warn` и текст «Без прав администратора») + кнопка темы 40×40 (иконка солнца в тёмной теме, луны в светлой).
- Карточки: фон `card`, рамка 1 px `line`, radius 16, внутренние отступы 18–24/20–28.

## 3. Экраны

### 3.1 Главная (`Main.dc.html`)
1. Заголовок «Главная», справа «zapret 1.8.5 · обновлений нет» (12, `faint`; данные из `UpdateChecker`).
2. **Карточка состояния** (padding 24/28, gap 28, в строку):
   - Круглая кнопка питания 112×112. Выкл: фон `raised`, рамка 2 px `line2`, иконка `dim`. Вкл: фон `accent-soft`, рамка 2 px `accent`, иконка `accent`, внешнее кольцо 8 px `accent-ring`. Клик = запуск/остановка (`ProcessManager`).
   - Справа: точка 8 px + «Обход включён» / «Обход выключен» (22/600); ниже 13 `dim`: «general (ALT2) · работает 00:42:17» или «Нажмите кнопку, чтобы запустить выбранную стратегию».
   - Ниже: подпись «Стратегия» (12 `dim`), выпадающий список (высота 40, radius 10, фон `raised`, рамка `line2`, ширина до 380) и ссылка «Подобрать лучшую →» (`accent`) — переход в «Проверку».
3. **Две карточки в ряд**:
   - «Фильтры»: строки «IPSet» [Выкл | Любой | Загруженный] и «Игры» [Выкл | TCP | UDP | TCP+UDP]. Сегменты: дорожка `seg` + рамка `line`, radius 9, padding 3; сегмент 28 px, radius 7, 12/500; выбранный — фон `segon`, текст `tx`; остальные — прозрачные, `dim`. Значения GUI ↔ `FilterManager.IPSET_MODES` (`off/any/loaded`) и `GAME_MODES` (`off/tcp/udp/tcp-udp`).
   - «Служба Windows»: справа статус (точка + текст: «Не установлена» `warn` / «Работает» `accent` / «Остановлена» `dim`), описание «Без службы обход выключится после перезагрузки.», кнопки «Установить с этой стратегией» (главная) и «Обновить hosts» (вторичная).
4. **Журнал** — карточка до низа окна. Шапка-кнопка 44 px: «Журнал» 14/600, счётчик «1 предупреждение» `warn`, справа «Свернуть/Развернуть». Тело: моноширинный 12/22, колонки время (72 px, `mute`) · уровень (44 px: ok `accent`, info `faint`, warn `warn`, err `err`) · текст `tx2`. Состояние свёрнутости сохранять в настройках.

### 3.2 Проверка (`Check.dc.html`)
- Справа от заголовка сегмент типа теста: «Сайты · HTTP / Ping» | «DPI · TCP 16–20».
- Слева карточка «Стратегии»: шапка (заголовок, «выбрано 4 из 6», главная кнопка «▶ Проверить»), таблица `28px | 1fr | 64 | 64 | 64 | 64`: чекбокс, профиль, Discord, YouTube, Google, Итог. Ячейки — плашки 12 моно: «ок» (`accent` на `accent-soft`), «нет» (`err` на `err-soft`), «—» (`mute`). Лучшая стратегия: фон строки `row` + бейдж «лучшая». Строка 44 px. Список сайтов взять из реального вывода `test zapret.ps1`.
- Справа карточка 260 px «Диагностика»: кнопка «Запустить», список проверок (точка + название + результат), внизу подсказка и кнопка «Исправить автоматически» (**новая функция — делать только после согласования с пользователем**). Secure DNS остаётся здесь же.

### 3.3 Списки (`Lists.dc.html`)
- Слева карточка 220 px: группы «Домены» и «IP-адреса»; элемент = человеческое имя (13) + имя файла (11 моно `faint`). Активный — фон `raised`.
- Справа редактор: шапка (имя файла моно 13, «● изменён» `warn`, кнопки «Вставить из буфера», «Отменить», главная «Сохранить»), поле с номерами строк (`gutter`), комментарии `#` цветом `mute`, фон `editor`, моно 13/24. Подвал 36 px: «9 доменов · UTF-8 · Ctrl+S — сохранить». Ctrl+S работает.

### 3.4 Настройки (`Settings.dc.html`)
- Карточка «zapret»: поле пути (моно) + «Обзор…»; под ним «Найдено 6 стратегий» (`accent`) или ошибка (`err`). Разделитель. «Версия X» + «Доступна Y — списки доменов сохранятся» (`warn`) + главная кнопка «Обновить» (видна только при наличии обновления; иначе «Проверить»).
- Карточка «Поведение»: три переключателя (`CTkSwitch`, 40×24, вкл — `accent`) с подписью и подсказкой: автозапуск, трей, проверка обновлений. Строка «Тема»: сегмент «Системная | Тёмная | Светлая».
- Карточка «Настройки GUI»: «Экспорт», «Импорт», «Сбросить» (текст `err`, рамка `danger-line`, с подтверждением).

## 5. Шрифты и иконки

- Интерфейс: **Onest** 400/500/600 (Google Fonts, OFL, есть кириллица). Журнал, имена файлов, пути, редактор: **JetBrains Mono** 400. Шрифты вшить в сборку и загрузить при старте через `AddFontResourceExW(path, FR_PRIVATE, 0)` (ctypes). Если загрузка не удалась — Segoe UI / Consolas.
- Размеры: H1 20/600, заголовок карточки 14/600, текст 13–14, подписи 12, служебное 11.
- Иконки: линейные, обводка 1.8–2 px, 18 px (меню), 40 px (питание). Взять Lucide (ISC): `power`, `activity`, `list`, `settings`/`sun`, `moon`, `shield-check`, `chevron-down`, `play`, `arrow-left-right`. Рендерить в PNG под обе темы (Pillow) и подставлять через `CTkImage(light_image=…, dark_image=…)`.

## 6. Плавная смена темы (обязательное требование)

`ctk.set_appearance_mode()` переключает тему мгновенно, поэтому нужен свой менеджер темы:
1. `ThemeManager` хранит текущие токены и список зарегистрированных `(widget, {параметр: токен})`, например `(card, {"fg_color": "card", "border_color": "line"})`.
2. При смене темы — анимация 400–500 мс, ease-out (cubic `1-(1-t)^3`): каждые ~16–25 мс интерполировать hex всех токенов между старой и новой палитрой и вызывать `widget.configure(...)` пакетно. В `tk.Text` (журнал, редактор) также перекрашивать теги.
3. В конце анимации записать финальные цвета и вызвать `set_appearance_mode`, чтобы `CTkImage` и стандартные элементы тоже переключились.
4. Если кадр не укладывается в 25 мс на машине пользователя (замерить), уменьшить число кадров до ~10. Запасной вариант: короткое «затемнение» окна через `attributes("-alpha")` 1 → 0.92 → 1 с переключением в середине.
5. «Системная» тема: читать `HKCU\Software\Microsoft\Windows\CurrentVersion\Themes\Personalize\AppsUseLightTheme` и раз в несколько секунд проверять, не сменилась ли она.
6. Выбор хранить в `settings` (`theme`: `system` | `dark` | `light`). Кнопка солнце/луна в sidebar и сегмент в Настройках — один и тот же параметр.

## 7. Поведение и состояния

- Кнопки во время долгих операций: блокировать и менять текст («Проверка…», «Обновление…»), как сейчас.
- Фокус с клавиатуры: видимая обводка 2 px `accent`. Переходы по разделам: Ctrl+1…4.
- Всё долгое (тесты, диагностика, обновление, службы) — в фоновых потоках, результат в UI через `after()`.
- Таймер «работает 00:42:17» обновлять раз в секунду, без нагрузки на CPU.

## 8. Порядок работы

1. Токены + `ThemeManager` + шрифты + каркас (sidebar, переключение разделов, плавная смена темы). Показать пользователю.
2. Главная (питание, стратегия, фильтры, служба, журнал).
3. Проверка (тесты + диагностика на одном экране).
4. Списки.
5. Настройки.
6. Удалить старые `_build_*` вкладки, проверить в обеих темах на 100 % и 150 % масштаба Windows, собрать `.exe`.

После каждого шага — короткий отчёт и скриншот в обеих темах. Новые функции («Исправить автоматически», «Установить с этой стратегией») — только после согласования с пользователем.
